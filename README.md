# MarioAndre-Faustino-CS134
Main project repository for CS 134

--Summary--
Collector is a run on of the Roll-A-ball game concept from Unity's tutorial. 

--Controls--
W A S D Keys are used for movement

Mouse controls is disabled, but can be reenabled by uncommenting the Ray section of PlayerController.cs

--How To Play--
When starting gameplay, the goal is collect the 25 coins scattered around the map. At the same time, there is a skeleton hunting you down for attempting to collect it's treasure. Once you collect the 25 coins, a pathway out of the Skeleton's territory will open and you can escape!
